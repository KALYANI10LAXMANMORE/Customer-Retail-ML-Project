# Final Machine Learning Project

## 📌 Project Overview

This project compares different Machine Learning algorithms using a customer retail dataset.

## 🚀 Algorithms Used

* Logistic Regression
* Decision Tree Classifier
* K-Nearest Neighbors (KNN)

## 📊 Features Used

* Quantity
* UnitPrice
* Country

## 🛠 Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## 🔍 Project Workflow

1. Data Loading
2. Data Preprocessing
3. Label Encoding
4. Data Visualization
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Accuracy Comparison

## 📈 Evaluation Metrics

* Accuracy Score
* Confusion Matrix

## 🎯 Learning Outcomes

* Understanding Machine Learning workflow
* Model comparison techniques
* Data preprocessing and visualization
* Performance evaluation

## ✨ Conclusion

This project helped in understanding and comparing multiple Machine Learning models on the same dataset.
